## 1. LLM(생성 모델) 비교표

| 항목 | **Qwen3-8B-AWQ (채택)** | GPT-4o-mini / Claude Haiku (외부 API) | Llama 3.1 8B | Gemma 2 9B |
|---|---|---|---|---|
| 배포 방식 | 자체 호스팅 (RunPod GPU + vLLM) | 외부 관리형 API | 자체 호스팅 | 자체 호스팅 |
| 라이선스 | Apache 2.0 | 비공개(API 약관) | Llama 3 Community License(상업적 제약 조항 있음) | Gemma 라이선스(사용 제약 조항 있음) |
| 다국어(한/영) 성능 | 한국어·영어 질의응답 검증됨 | 우수 | 보통 | 보통 |
| 데이터 외부 전송 | 없음 (자체 GPU 내 처리) | 있음 (요청 내용이 외부 서버로 전송) | 없음 | 없음 |
| 비용 구조 | GPU 사용 시간 기준 고정 비용 | 토큰당 종량제 | GPU 사용 시간 기준 고정 비용 | GPU 사용 시간 기준 고정 비용 |
| 공식 AWQ 양자화 체크포인트 | 제공 | 해당 없음 | 커뮤니티 제공(공식 아님) | 커뮤니티 제공(공식 아님) |
| 채택 이유 | 이민·비자 상담은 사용자의 학력·경력·개인 상황이 포함된 민감한 질의가 많아, 외부 API로 데이터가 나가지 않는 자체 호스팅을 우선 고려. Apache 2.0 라이선스로 상업적 사용 제약이 없고, 공식 AWQ 체크포인트 덕분에 8B 규모로도 GPU 비용을 낮추면서 자체 호스팅 구성이 단순함 | — | 라이선스의 상업적 사용 제약 조항 때문에 후순위 | 라이선스의 사용 제약 조항 때문에 후순위 |

**참고**: 외부 API(GPT-4o-mini, Claude Haiku 등)는 응답 품질·속도에서 강점이 있으나, MVP 단계에서는
①개인정보가 포함된 상담 내용을 외부로 보내지 않는다는 원칙, ②토큰당 과금이 아닌 고정 비용으로
운영 예산을 예측 가능하게 유지한다는 두 가지 이유로 자체 호스팅을 선택했습니다. 향후 응답 품질이
병목이 되면 외부 API를 보조 옵션으로 재검토할 수 있습니다.

## 2. 벡터 데이터베이스 비교표

| 항목 | **pgvector (채택)** | Pinecone | Weaviate | Milvus |
|---|---|---|---|---|
| 배포 방식 | PostgreSQL 확장(자체 호스팅) | 완전 관리형 SaaS | 자체 호스팅 / 관리형 둘 다 가능 | 자체 호스팅 / 관리형 둘 다 가능 |
| 별도 인프라 필요 여부 | 불필요 — 기존 PostgreSQL에 확장만 추가 | 별도 서비스·계정 필요 | 별도 서버(컨테이너) 필요 | 별도 서버(컨테이너, 보통 다중 컴포넌트) 필요 |
| 트랜잭션 정합성 | 관계형 데이터(사용자·분석 결과 등)와 동일 DB·동일 트랜잭션으로 처리 가능 | 별도 시스템이라 애플리케이션 레벨에서 정합성을 맞춰야 함 | 별도 시스템 | 별도 시스템 |
| 인덱스 방식 | HNSW, IVFFlat | 자체 관리형 인덱스 | HNSW 등 | HNSW, IVF 등 다수 |
| 비용 구조 | 기존 PostgreSQL 인스턴스 비용에 포함(추가 비용 없음) | 벡터 수·쿼리량 기준 별도 과금 | 자체 호스팅 시 인프라 비용만 | 자체 호스팅 시 인프라 비용만(컴포넌트가 많아 운영 부담 큼) |
| 채택 이유 | 이미 PostgreSQL을 관계형 데이터(사용자, 분석 결과, 정책 문서 메타데이터)에 쓰고 있어, 정책 문서 임베딩만 별도 벡터DB로 분리하면 두 시스템 간 동기화·정합성 문제가 생김. pgvector는 같은 DB·같은 트랜잭션 안에서 관계형 조회(국가·비자별 필터)와 벡터 유사도 검색을 함께 할 수 있어 MVP 규모(수천 건)에서 별도 인프라를 두는 것보다 단순하고 저렴함 | — | — | — |

**참고**: Pinecone/Weaviate/Milvus는 수백만~수억 건 규모의 벡터 검색에서 pgvector보다 확장성이
좋다고 알려져 있습니다. 현재 데이터 규모(정책 청크 82건, 직업 임베딩 약 1,944건)에서는
그 차이가 체감되지 않아 채택하지 않았고, 향후 데이터가 크게 늘어나면 재검토 대상입니다.
