데이터베이스 ERD
논리 모델 · 물리 모델

Flyway 마이그레이션 V1~V10(PostgreSQL 16, pgvector 포함)을 기준으로 실제 스키마와 동일하게 그린 ERD입니다. 논리 ERD는 비즈니스 관점의 엔터티·속성·관계를, 물리 ERD는 실제 테이블·컬럼·타입·PK/FK/UK 제약을 보여줍니다. 테이블 수가 많아(19개) 물리 ERD는 도메인 4개로 나눠 표시합니다.

표기법 (Crow's Foot)

  • || 정확히 1
  • |o 0 또는 1
  • }o 0개 이상
  • }| 1개 이상
  • 예: A ||--o{ B = A 하나가 B 여러 개를 가짐

물리 ERD 키 표기

  • PK 기본키
  • FK 외래키
  • UK 고유 제약(Unique)
  • 도메인 다이어그램에 등장하는 다른 도메인 테이블은 PK만 표시한 참조용 박스입니다.

논리 ERD
PHYSICAL ERD
물리 ERD 개요

실제 PostgreSQL 스키마 기준(Flyway V1~V10). 총 19개 테이블을 4개 도메인으로 나눠서 봅니다 — 한 화면에 다 넣으면 선이 뒤엉켜서 오히려 안 보이기 때문입니다. 다른 도메인의 테이블을 참조하는 경우, 해당 다이어그램에는 PK만 있는 참조용 박스로 표시했습니다.

도메인 테이블 개수
② 인증/계정users, refresh_tokens, email_verification_tokens, password_reset_tokens4
③ 기준정보countries, visa_programs, visa_rules, occupations4
④ 분석user_profiles, analyses, analysis_country_results, analysis_result_reasons, analysis_occupation_matches, analysis_share_tokens6
⑤ AI상담/RAGchat_sessions, chat_messages, chat_message_sources, policy_documents, policy_chunks5
합계19

PHYSICAL ERD · DOMAIN 1
인증 / 계정

V1(users), V5(refresh_tokens), V6(email_verification_tokens), V7(password_reset_tokens), V10(Google OAuth 컬럼 추가).

erDiagram

    users ||--o{ email_verification_tokens : "user_id"
    users ||--o{ password_reset_tokens : "user_id"

    users {
        bigint user_id PK
        varchar email UK
        varchar password_hash "NULL 허용(Google 계정)"
        varchar user_name
        varchar account_status "ACTIVE/INACTIVE/WITHDRAWN"
        varchar auth_provider "LOCAL/GOOGLE"
        varchar google_sub UK "NULL 허용"
        boolean email_verified
        timestamptz created_at
        timestamptz updated_at
    }
    refresh_tokens {
        bigint token_id PK
        bigint user_id FK
        varchar token_hash UK
        timestamptz expires_at
        timestamptz revoked_at
        timestamptz created_at
    }
    email_verification_tokens {
        bigint token_id PK
        bigint user_id FK
        varchar token_hash UK
        timestamptz expires_at
        timestamptz used_at
        timestamptz created_at
    }
    password_reset_tokens {
        bigint token_id PK
        bigint user_id FK
        varchar token_hash UK
        timestamptz expires_at
        timestamptz used_at
        timestamptz created_at
    }

PHYSICAL ERD · DOMAIN 2
기준정보 (Reference / Master Data)

V1(countries, visa_programs), V3(visa_rules), V4(occupations.embedding 추가). visa_rules는 country_code와 visa_program_id를 모두 직접 FK로 갖습니다.

erDiagram
    countries ||--o{ visa_programs : "country_code"
    countries ||--o{ occupations : "country_code"
    countries ||--o{ visa_rules : "country_code"
    visa_programs ||--o{ visa_rules : "visa_program_id"

    countries {
        varchar country_code PK
        varchar country_name_ko
        varchar country_name_en
        boolean is_active
        timestamptz created_at
    }
    visa_programs {
        bigint visa_program_id PK
        varchar country_code FK
        varchar program_code UK
        varchar program_name_ko
        varchar program_name_en
        text official_url
        boolean is_active
    }
    visa_rules {
        bigint rule_id PK
        varchar country_code FK
        bigint visa_program_id FK
        varchar factor_code "AGE/EDUCATION/EXPERIENCE_YEARS 등"
        varchar operator "비교 연산자(>=, <=, BETWEEN, =)"
        numeric min_value
        numeric max_value
        smallint score
        text description
        date effective_from
        date effective_to
        timestamptz last_verified_at
        boolean is_active
    }
    occupations {
        bigint occupation_id PK
        varchar country_code FK
        varchar classification_system "NOC/ANZSCO/SOC"
        varchar occupation_code
        varchar occupation_title
        text occupation_description
        varchar skill_level
        vector embedding "768차원, multilingual-e5-base"
        boolean is_active
    }

분석 (Profile & Analysis)

V1 기준. users/countries/visa_programs/occupations는 다른 도메인 테이블이라 PK만 표시한 참조용 박스입니다.

        bigint reason_id PK

        bigint match_id PK

        bigint occupation_id FK

        smallint match_rank
        text match_reason

        bigint share_token_id PK
        bigint analysis_id FK
        varchar share_token UK
        timestamptz revoked_at
    }

        bigint user_id PK
    }

        bigint analysis_id PK
    }
    visa_programs {
        bigint visa_program_id PK
    }
    countries {
        varchar country_code PK

    chat_sessions {
        bigint session_id PK
        bigint user_id FK
        bigint analysis_id FK "NULL 허용"

        varchar session_title
        varchar country_code "히스토리 필터용 비정규화 컬럼"
        timestamptz created_at
        timestamptz updated_at
    }
    chat_messages {
        bigint message_id PK
        bigint session_id FK
        varchar message_role "USER/ASSISTANT"
        text message_content
        boolean answerable
        timestamptz created_at
    }
    policy_documents {
        bigint document_id PK
        varchar country_code FK
        bigint visa_program_id FK "NULL 허용"
        varchar document_title
        varchar document_type
        text source_url UK
        date effective_date
        timestamptz verified_at
        boolean is_active
    }
    policy_chunks {
        bigint chunk_id PK
        bigint document_id FK
        int chunk_index
        varchar section_title
        text chunk_content
        int token_count
        vector embedding "768차원, multilingual-e5-base"
    }
    chat_message_sources {
        bigint source_id PK
        bigint message_id FK
        bigint chunk_id FK
        numeric relevance_score "0~1"
        text quoted_text
    }
