## 한계 및 주의사항

- **이 문서의 "PASS"는 자동 회귀 테스트가 아니라 특정 시점의 수동 확인 기록이다.** 테스트 수행일 이후 관련 코드가 바뀌었다면 재검증이 필요할 수 있다 — 특히 ST_003/ST_006처럼 수행일이 오래된 항목은 이후 여러 PR(#10~#29)을 거치며 관련 코드가 계속 바뀌었으므로, 데모 직전에는 최소 ST_002~ST_006을 한 번 더 스모크 테스트하는 것을 권장한다.
- GCP 배포는 로컬과 DB 버전이 다르다(PostgreSQL 18+pgvector 0.8.2 vs 로컬 16+0.8.0) — 로컬에서 통과했다고 GCP에서도 100% 동일하게 동작한다고 단정할 수 없어, ST_008처럼 배포 환경 자체에서 별도로 검증한 항목을 따로 표시했다.
- ST_005(RAG)는 로컬은 Ollama(gemma2:latest), 배포는 vLLM(Qwen3-8B-AWQ)로 실제 사용 모델이 다르다 — 답변 품질은 모델별로 차이가 있을 수 있으나, "근거 없으면 거부"라는 하드 룰은 모델과 무관하게 코드 레벨에서 강제되므로 두 환경 모두 안전하다.
