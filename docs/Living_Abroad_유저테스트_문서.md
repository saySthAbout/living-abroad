# Living Abroad — 유저 테스트(User Acceptance Test) 문서

- 작성일: 2026-07-27
- 성격: 이 문서는 단위/통합/[시스템 테스트 문서](Living_Abroad_시스템테스트_문서.md)와 달리 **개발자 관점이 아닌, 서비스를 처음 접하는 실제 사용자 관점**에서 진행하는 체크리스트다. **아래 테스트결과는 전부 미실행(-) 상태다** — 아직 실제 제3자 사용자에게 실행되지 않은 UAT 계획이며, 테스터/수행일/결과 칸은 실제로 진행하는 사람이 직접 채운다.
- 참고 문서: `docs/Living_Abroad_요구사항_4-8.md` §5.4 사용성(NFR-UX) 요구사항

## 테스트 대상 및 준비물

- 대상: `https://34.132.107.128.sslip.io` (배포 환경 기준. 로컬로 진행 시 `http://localhost:5173`)
- 준비물: 테스트용 이메일 주소 1개(가능하면 실제 수신 가능한 메일함), 데스크톱 브라우저 1개 + 모바일 기기 또는 브라우저 반응형 모드
- 페르소나: "해외 취업/이민을 막연히 고려 중인 20~30대 직장인. 비자 요건이나 이민 정책 용어에는 익숙하지 않고, 이 서비스를 검색이나 지인 추천으로 처음 알게 되어 접속했다."
- 테스터에게 사전 설명하지 않는 것을 권장: 화면 흐름, 버튼 위치 등 — "안내 없이도 헤맴 없이 완주할 수 있는가"가 이 체크리스트의 핵심 목적

## 한계

- 이 체크리스트는 아직 실제 제3자 사용자에게 실행되지 않았다 — 개발자 본인이 셀프 진행하면 "처음 보는 사람"의 혼란 지점을 놓치기 쉬우므로, 가능하면 프로젝트에 관여하지 않은 지인에게 진행을 부탁하는 것을 권장한다.
- 접근성(스크린 리더, 키보드 내비게이션 등)은 이 체크리스트 범위 밖이며 별도 검토가 필요하다.
